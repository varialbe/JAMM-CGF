JAMM-CGF for Windows x64
Run cgfmm-gui.exe for the desktop app, or cgfmm.exe --help in a terminal.
No system .NET installation is required. Native libraries are extracted to the
user's temporary directory on first launch; keep that directory writable.
Game files are not included. Use your legally obtained legacy 2023 game.
Source, help and license: https://github.com/varialbe/JAMM-CGF
