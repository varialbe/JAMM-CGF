Compatibility

These combinations are supported by recorded archive builds or runtime checks in the repository reports. A reported build does not guarantee every third-party mod revision behaves the same way.

Public five-pack

The public five-pack used in the reports is Antiquity, PWB, The Abyss, Colour Expansion and Verdant. Silo and Weather Pack were built with that pack at zero pack-specific conflicts. Endless Ocean completed a route across the five-pack's extended east boundary using its seeded chunk stream.

  • The Silo: five-pack and all-seven archive builds passed; the Area follow anchor tracks Cave Expansion's moved and rotated MissileSilo.
  • Weather Pack: five-pack and all-seven builds passed with zero Weather Pack conflicts and all 53 Weather assets accepted.
  • Endless Ocean: the five-pack route crossed the generated boundary, streamed terrain and returned west with generated instances released.

First-party defaults

JAMM Perf, Smooth, HD Lite and Console are documented together as a verified first-party combination. The site recipes are source packages that still build locally against the configured legacy base.

  • Example Fish was verified alongside Harbor Pack and Showcase Upgrades.
  • Example Rod uses the shared Items runtime and stable item keys, so its save ownership is independent of its current numeric slot.

Know the limits

Compatibility is tied to the August 2023 legacy VM archive and the tested package versions. The current Steam YYC build is not a supported base. Legacy whole-archive mods can edit the same code or room entries; JAMM reports those overlaps and profile choices determine the retained changes.

The reports contain some broader all-seven runs. One Silo all-seven save run hit an existing Maize patrol crash after the four catches had been deposited; the save was independently reloaded and checked. This is recorded as a limitation of that pack combination, not a Silo package failure.

Keep boat contents and live lure interactions clear when changing profiles because some legacy save sections still use numeric object IDs. Back up saves before profile changes.
