Build a modded game from source

JAMM combines mod packages with your own untouched August 2023 data.win. The downloads here contain recipes and original ModKit source, never a game archive or extracted game art.

How a build worksSee tested combinations →

Install a package

  1. Set up JAMM with a read-only copy of the supported August 2023 legacy game archive. The current Steam YYC archive is not a compatible build base.
  2. Download a source ZIP and add it from JAMM’s Add mods flow. Keep each package enabled in the profile you want to build.
  3. Check the profile, then build or install to a separate game copy. JAMM backs up the installed original; your source archive stays untouched.

Package ZIPs contain source manifests, original hooks, recipes and authored assets. JAMM compiles them locally against your base game.
