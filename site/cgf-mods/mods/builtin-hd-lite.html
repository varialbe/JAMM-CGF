What it does

JAMM HD Lite fits the game to your window or monitor while preserving its aspect ratio. It uses the original textures and defaults to fullscreen on first launch.

Requirements

  • JAMM-CGF configured with the untouched August 2023 legacy VM data.win (bytecode 16).
  • A separate game copy for the built output; the current Steam YYC archive is not a compatible build base.

Install

  • Download this source ZIP.
  • In JAMM, choose Add mods and import the ZIP.
  • Enable it in a profile, run Check, then build or install to a separate game copy.

In-game controls

  • Press F11 to toggle between fullscreen and windowed mode.

How it works

The recipe retains the original texture pages and enables the GameMaker runner's Scale and Interpolate flags. It sets a black window background and installs a persistent obj_jamm_hd controller in the native rooms.

At Room Start, the controller records every original view port, including hidden views. It fits the 1200 × 720 logical application surface using the smaller of window-width/1200 and window-height/720, then resizes the native surface and scales the saved view ports by the same factor. The runner letterboxes that surface to preserve aspect ratio and maps room mouse coordinates.

The controller keeps GUI coordinates at 1200 × 720 and watches for window or recreated-surface changes, including fullscreen switches. F11 toggles fullscreen and jamm_hd.ini stores the selection. It changes presentation sizing; it does not replace or repack the game's original textures.

FAQ

Does HD Lite upscale or replace the game textures?

It scales the original 1200 × 720 application surface and letterboxes it to preserve the aspect ratio. It keeps original texture pages.
