What it does

JAMM Smooth interpolates the camera and motion for a 60 or 120 FPS display target. It preserves the legacy simulation cadence of 30 ticks per second and supports the game's Tab speed-up.

Controls

  • Press F7 to cycle 60 FPS, 120 FPS and off. The initial target is 120 FPS.

How it works

The obj_jamm_smooth controller schedules logic ticks from elapsed time. Between ticks it deactivates active instances, wakes them for drawing, and temporarily interpolates selected positions, angles and camera coordinates from the last two simulation states.

Keyboard or mouse edges on a render-only frame can promote it to a logic tick. The controller replays Begin Step for the woken instances before input handlers run. At the end of drawing it restores the simulation poses.

The generator replaces delta_time reads in Girl.Step with the elapsed time between logic ticks. It also verifies the QuestEngine counter reset so the controller can replay that reset before drawing render-only frames.
