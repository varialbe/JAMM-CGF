What it does

JAMM Smooth interpolates the camera and motion for a 60 or 120 FPS display target. It preserves the legacy simulation cadence of 30 ticks per second and supports the game's Tab speed-up.

Requirements

  • JAMM-CGF configured with the untouched August 2023 legacy VM data.win (bytecode 16).
  • A separate game copy for the built output; the current Steam YYC archive is not a compatible build base.
  • The legacy QuestEngine Begin Step reset and Girl.Step timing anchors must remain available to the recipe.

Install

  • Download this source ZIP.
  • In JAMM, choose Add mods and import the ZIP.
  • Enable it in a profile, run Check, then build or install to a separate game copy.

In-game controls

  • Press F7 to cycle 60 FPS, 120 FPS and off. The initial target is 120 FPS.

How it works

The persistent obj_jamm_smooth controller accumulates elapsed real time and runs the original game simulation on its preserved 30 ticks/second logic cadence. At a 60 or 120 FPS target, display frames between logic updates are render-only; they do not run an additional full game tick.

On a render-only frame, Smooth freezes the active instances and wakes them for drawing, then temporarily interpolates selected positions, angles and camera coordinates between the last two simulation states. It restores each simulation pose after drawing. A keyboard or mouse edge received on a render-only frame can promote that frame to a full logic tick; the controller replays Begin Step for the woken instances before input handlers run.

The recipe replaces delta_time reads in Girl.Step with elapsed time since the previous logic tick and verifies the legacy QuestEngine Begin Step reset anchor, which it replays before render-only frames. The F7 key cycles 60 FPS, 120 FPS and off; [Smooth] TargetFPS in jamm_smooth.ini persists the setting. Compatibility depends on the expected legacy timing anchors surviving other profile edits.

Measured performance

Seven-pack build, dock: 48.4 ms without Smooth vs 51.4 ms with Smooth (mean of 2 runs) — loop cost is neutral within noise. Smooth's benefit is frame pacing and off-screen culling, not raw loop time.

With JAMM Perf generator ≤ 6, Smooth masked the Perf regression (Perf + Smooth = 48.4 ms vs Perf alone = 98 ms). Generator 7 removes the need for that pairing.

FAQ

Does Smooth raise simulation speed?

No. Simulation remains on its legacy 30 ticks per second cadence; Smooth adds render-only frames between those ticks.

Can I turn it off?

Press F7 to cycle through 60 FPS, 120 FPS and off. The selected target is saved in jamm_smooth.ini.
