What it does

JAMM Perf reduces work in fish collision, avoidance and scenery updates in the legacy game. Its experimental mode also reduces how often eligible distant fish run part of their logic.

Requirements

  • JAMM-CGF configured with the untouched August 2023 legacy VM data.win (bytecode 16).
  • A separate game copy for the built output; the current Steam YYC archive is not a compatible build base.
  • Scheduling is optional and experimental; press F8 to enable or disable it.

Install

  • Download this source ZIP.
  • In JAMM, choose Add mods and import the ZIP.
  • Enable it in a profile, run Check, then build or install to a separate game copy.

In-game controls

  • Press F8 to switch between mode 0 (base optimizations) and mode 1 (base optimizations plus experimental scheduling).

How it works

The built-in recipe guards Magmer and Volteen light updates against stale instance IDs, skips a deep-rock collision query in fish states that cannot use its result, and avoids the trawler net collision query when the fish is ineligible for it. The avoidance patch hoists fixed radius and force expressions. The scenery object caches its depth transform while continuing to update its parallax position.

Optional F8 scheduling wraps the base Fish End Step. Before a fish can be skipped, the controller caches its object ancestry and requires a standard FishSmall or FishMedium lineage. FishLarge/FishHuge, named special lineages (Dragon, Noctis, Torby, Ghost, Abyssal, Kingfish, Shaku, Bagu and Curby), custom Step-event logic and custom user-event logic are excluded. It also waits one full End Step after an object type changes.

Only safe swimming or paused fish states are candidates. Fish are excluded if always-zoned, nether, deactivated, hollow, dead, dragged, aboard, or under thrall override; active lunge/flee states are not scheduled. A candidate stays unscheduled near every active view, the legacy visibility view 3, Girl, CatSwim, Lure, Boat or Net, using lunge-range-aware distance margins. The remaining instances are staggered by instance ID and tick using the interval in jamm_perf.ini (default 4). Engine alarms, motion and Draw still run; selected End Step logic is skipped. F8 toggles the persisted experimental mode.

The builder's general object-index guards are a separate compatibility pass: CGF-INSTANCE-004 replaces eligible <Object>.object_index type reads with the typed object constant; 005 guards eligible instance-member reads and writes; 007 safely handles supported lookup-result reads. They address known inactive-instance hazards and do not claim to validate arbitrary dynamic IDs. No benchmark figures are published here unless measured entries are supplied in content/benchmarks.json.

Measured performance

Measured 2026-11-21 on a Ryzen 7 5700X / RTX 2070 Super (Proton, 1200×720 window), 30-second captures, seed 1337, game-loop time per tick. Cat Goes Fishing's GameMaker loop is single-threaded and CPU-bound, so loop time — not GPU load — decides FPS.

Since generator 7, JAMM Perf adds no per-frame code by default: vanilla +Perf is byte-identical to vanilla; a five-pack build measured 85.7 → 81.3 ms (dock); a seven-pack build measured +0.2 % (dock) and +1.2 % (deepwater), within run-to-run noise.

Older builds (generator ≤ 6) installed the fish neighbour grid unconditionally and made large packs up to 2× slower when JAMM Smooth was not also enabled. Rebuild your profile to pick up the fix.

Weak-PC preset (fish scheduling interval 8, HD-Lite off): about 21 % faster loop on a seven-pack profile build.

FAQ

Does scheduling pause every fish?

No. It only considers standard small and medium fish in safe swimming or paused states, away from every active view, the player, lures, boats, swimmers and nets. Special ancestry, custom Step events, dragging, hooked, netted or boat fish are excluded.

Does F8 save the mode?

Yes. The mode is stored in jamm_perf.ini; the default base optimization mode is off for scheduling.
