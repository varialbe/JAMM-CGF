What it does

JAMM Console adds a keyboard-operated overlay for testing progression and equipment in the legacy game. You can grant gear, set money and level, or fill the Fishalog from the command prompt.

Requirements

  • JAMM-CGF configured with the untouched August 2023 legacy VM data.win (bytecode 16).
  • A separate game copy for the built output; the current Steam YYC archive is not a compatible build base.

Install

  • Download this source ZIP.
  • In JAMM, choose Add mods and import the ZIP.
  • Enable it in a profile, run Check, then build or install to a separate game copy.

In-game controls

  • Press F12 or backtick to toggle the console. Enter submits, Up and Down browse history, and Escape closes it.
  • help lists commands, clear clears the log, and close or exit closes the overlay.
  • unlockgear unlocks equipment, upgrades, hats, HUD menus and nightfall. unlockall also maxes your level and fills the Fishalog.
  • level <n> sets your level and maxlevel uses the game's maximum. catalog all or unlockfish marks the fish caught.
  • money <n> sets your dollars and money +<n> adds dollars.

How it works

The recipe places persistent obj_jamm_console instances in NewWorld and room11. Begin Step reads and normalizes the command buffer, consumes gameplay keys while the overlay is open and submits commands. End Step maintains the rod-swing lock; Draw GUI renders the prompt and scrolling log. F12 or backtick toggles it; Enter submits, Up/Down browse history and Escape closes it.

help lists clear, close/exit, unlockgear, unlockall, level <n>, maxlevel, catalog all/unlockfish, money <n> and money +<n>. Commands work on live gear/item tables and Fishalog arrays, so profile-added items are included. The controller watches the active SaveManager instance and slot to reset slot-specific bookkeeping. Changed progress is written by the game's normal save flow; the log/history itself is in memory.

On modded builds the shared number_to_dollar_string formatter uses one truncated decimal with K/M/B/T/Qa at $10,000 and above: $9,999 remains unchanged, while larger examples display as $25.0K, $3.4M, $9.5B, $3.4T or $1.0Qa. The wallet supports values through 1e15 and the money command accepts the same range. Fish sale values still have a separate 100-million cap. The Weather API extends the same Console with the weather command.

FAQ

What is the largest money value?

The modded wallet and Console support values through 1e15. Fish sale value retains its separate 100 million cap.

How are large amounts shown?

The display stays exact below $10,000; then uses one truncated decimal and K, M, B, T or Qa, such as $25.0K, $3.4M, $9.5B and $3.4T.
