What it does

Goldie is a small, shallow-water fish found near the dock. Glowfin is a medium nocturnal fish that pulses cyan and lime and can dart away from a nearby cast lure.

Requirements

  • JAMM-CGF configured with the untouched August 2023 legacy VM data.win (bytecode 16).
  • A separate game copy for the built output; the current Steam YYC archive is not a compatible build base.
  • Fish hooks must use GameMaker 1.4 GML syntax.

Install

  • Download this source ZIP.
  • In JAMM, choose Add mods and import the ZIP.
  • Enable it in a profile, run Check, then build or install to a separate game copy.

How it works

The ModKit manifest declares two species with stats, single-frame PNG sprites and coordinate rectangles. The builder generates namespaced fish objects inheriting from FishSmall or FishMedium, hook scripts when present, a package initializer and Fish API registration. That initializer calls jamm_fish_register with stable package and fish keys. The shared runtime assigns Fishalog entries and saves discovery/catch progress by object name in [JAMM_Catalog] in the native slot INI.

The initializer places four Goldies in x=1100–2200, y=1400–1900 and three Glowfins in x=1400–2800, y=1600–2300. Goldie uses the normal shallow FishSmall behavior. Glowfin's Create hook selects a glow phase and dart cooldown. Its End Step hook runs after inherited fish behavior: at night it pulses tint and, while swimming, darts away from a cast lure within 120 pixels after cooldown; during the day it dims and sinks. Catching and selling remain native.

Goldie manifest walkthrough

A ModKit fish entry declares the stable key, parent size, art, stats and initial spawn region. The builder converts this data into a namespaced GameMaker object and initializer call.

{
  "id": "example-fish",
  "name": "Example Fish",
  "fish": [{
    "key": "goldie",
    "name": "Goldie",
    "size": "small",
    "sprite": "art/goldie.png",
    "value": 300,
    "spawn": { "x": [1100, 2200], "y": [1400, 1900], "count": 4 }
  }]
}
