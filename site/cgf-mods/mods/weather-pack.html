What it does

Weather Pack brings Super Sunny, Rainy, Windy and Fog to the legacy daylight cycle. Each weather has its own sky, sound and two surface fish. A Lightbulb lure near the surface thins the fog.

Requirements

  • JAMM-CGF configured with the untouched August 2023 legacy VM data.win (bytecode 16).
  • A separate game copy for the built output; the current Steam YYC archive is not a compatible build base.
  • JAMM Console is installed by the merged Weather runtime if the profile does not already include it.

Install

  • Download this source ZIP.
  • In JAMM, choose Add mods and import the ZIP.
  • Enable it in a profile, run Check, then build or install to a separate game copy.
  • Open the in-game Console with F12 and type weather to list and select available weather IDs.

In-game controls

  • Open the JAMM Console in the fishing world with F12. Type weather to list the installed weather IDs.
  • Use weather super-sunny, weather rainy, weather windy or weather fog to request a weather. Qualify a shared short ID as weather weather-pack:fog. A daytime request made at night waits for daylight.
  • Use weather clear for clear skies or weather auto to resume the forecast.

How it works

At profile build time, JAMM reads every enabled package's weathers[] declaration and creates one persistent obj_jamm_weather controller with a composed registry. Weather IDs are qualified by package (weather-pack:fog) so entries from different packages can share a short ID. The controller sorts IDs and draws a weighted forecast from the save-slot seed and local clock hour; reopening the same slot during the same hour resumes the stored start/end window. A new hour produces the next forecast. The native is_it_night() and AmbianceController phase clock gate daytime weather.

The forecast, seed and qualified weather ID are stored under [Weather] in jamm-weather-<slot>.ini beside the game's save slots. When replaceDayFish is active, the controller parks eligible free-swimming vanilla surface fish with a home and surface-band position. Their existing room and path records are retained; on clear or nightfall they return to their previous behavior. Weather Pack's fish are ordinary Fish children registered through the Fish and Catalog runtimes, spawned in free surface water near the current shore or boat, and retire when the weather ends. Catches in progress finish normally.

The runtime patches the legacy ParallaxBackground.Draw sky, Sea.Step and x_pos_to_y_off wave/tint behavior, color_from_depth lighting, Fish.End Step population gate and Girl.Step music gain. Weather sky layers wrap across the camera with padded repeat edges. The four Pack entries compose sky layers, water tint, waves and light. Fog additionally dims foreground haze and particles when the native Lightbulb lure is near the surface.

Each weather can provide Ogg Vorbis music and ambience. The controller fades those channels against the native surface track and honors the game's music volume and lure-depth attenuation. Weather requests from the Console queue until the phase allowed by the manifest; weather clear clears the override and weather auto resumes the forecast. The generated profile needs exactly one surviving copy of each required hook anchor; missing or ambiguous anchors stop the build.

Measured performance

Seven-pack build, dock: 48.4 ms → 55.6 ms with Weather Pack (mean of 2 runs; one run was noisy at 58.7 ms). The particle/lighting overlay is the most expensive first-party mod we measured; disable it first on weak CPUs.

FAQ

Why is a requested weather waiting?

The default weathers run in daylight. A request made during the game's night phase waits until the vanilla night predicate allows it.

Where is the forecast saved?

jamm-weather-<slot>.ini sits beside the game saves and stores forecast state by slot. Copy it with the save to retain the same forecast on another machine.
