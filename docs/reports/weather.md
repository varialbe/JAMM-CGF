# Weather API and Weather Pack

The [Weather API](../modding/weather.md) composes ModKit `weathers[]` from every enabled package into a single persistent controller. The [Weather Pack](../../examples/modkit/weather-pack/) demonstrates its four daytime weathers, eight surface fish, original Ogg Vorbis tracks, and Fog's interaction with the native Lightbulb lure.

## Legacy integration

The August 16 legacy archive uses `AmbianceController` for its real-time phase clock and `LightingSystem` for night lighting. `is_it_night()` also accounts for the day lock and gear effects. `ParallaxBackground.Draw` paints the sky and the horizontal terrain layers. The near-surface Sea sprite has its own drift. Hull and swimmer motion also read `x_pos_to_y_off`. `Girl.Step` sets `background_music` gain from camera activity, lure depth, darkness and the player volume setting. Daytime Fish instances are placed in the room with native paths. Their End Step changes their state and path when the vanilla night predicate applies.

The generated controller reads the active save slot and persists its seed and forecast beside that slot's native save. It parks eligible vanilla Fish instances while replacement is active and restores their original instances when the weather clears or night starts. Weather species use the shared Fish and Catalog runtimes with ordinary Fish parents and their own school placement. The profile builder adds the weather anchors to the selected code after legacy conflict resolution and checks that exactly one copy of each anchor remains.

## Round 2 art review

Weather Pack 1.0.1 rebuilds the fog ribbons with matching heights and horizontal tangents at the repeat boundary. Both rendered fog bands have byte-identical left and right edge columns. The atlas puts wrapped pixels beside each repeated sprite, outside its frame, so filtering samples the neighbouring tile across the join. A regression test checks both sides of a translucent sample and its original frame dimensions.

The revised donor comparison pairs the finished sprites with their main body donors at the same pixel scale. The local sheet is `~/jamm-night/weather/art-review.png`. ## Verification

Use `dotnet build -c Release`, `dotnet test -c Release`, and `node --test scripts/test-weather-runtime.mjs`. The synthetic tests cover manifest diagnostics, package coexistence with the same short ID, a preinstalled console, missing or duplicate anchors, deterministic weighted selection, persistence by qualified ID, day/night activation and parking/restoration. The two-package test builds and reloads a legacy-format archive with one controller.

The source archive adds 27 code entries, eight fish objects, 18 sprites and eight sounds. It edits zero existing code entries, objects or rooms. Pairwise checks produced zero weather conflicts with TGE, Antiquity, PWB, Abyss, Colour, Verdant and Cave. Cave adds a sprite called `spr`. The combined build caught a GM 1.4 compiler symbol collision with that name; the runtime now uses a namespaced sprite variable.

The dock probe is available through `jamm-modmaker bench <profile.win> <new.win> --scene weather`. It loads a disposable save, uses the console command handler to trigger each weather, holds the camera at the dock, and records the active ID, lighting phase, vanilla and custom surface fish counts, catalog registration and playback voices. It captures clear day, all four weathers, clear restoration, and vanilla night with a daytime weather requested. The VPS runner checks for a game process and acquires the shared game lock before launch, with a 600-second limit per profile.

### Runner notes

The first Wine launch stopped at Steam initialization. Refreshing the existing client under the shared game lock allowed the next launch to reach NewWorld. The first successful game startup exposed a native Fish field that Rod normally initializes later. Weather schools now seed that field when they spawn.

The dock archive controls the legacy day/night predicate and lighting clock to give each profile the same phase inputs. These controls are installed only by the bench command. The Wine host exposed its dummy audio device, so the bench measures running GameMaker audio voices and the archive check verifies the Ogg assets. Speaker output was outside the VPS coverage.

The complete donor comparison stays on the VPS. A gameplay-only review sheet and the four solo weather captures were sent via the requested Telegram script.

In the solo run, the sampled upper sky averaged 173–222 across the four weathers, 224 in clear daylight, and 14 at night on a 0–255 luminance scale.

Executable runs were serialized behind the shared game lock. The all-seven capture reached its night sample about four minutes after launch, within the 600-second budget.

Reopening the test slot in the same local hour preserved the seed, qualified forecast ID, and start and end seconds. Reopening after the next hour preserved the seed and computed a new forecast.
