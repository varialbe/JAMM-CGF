# v0.9.1 release verification

Verified locally on Linux on 2026-11-16 against the legacy 2023 base and local
mod fixtures. See [fixture setup](../real-file-tests.md).

- `dotnet build -c Release`: passed, zero warnings and errors.
- `dotnet build tools/Jamm.ModMaker -c Release`: passed, zero warnings and errors.
- `dotnet test -c Release --no-build` with `JAMM_ORIGINAL` and `JAMM_MODS_DIR`:
  295 Core tests and 103 GUI tests passed; zero failures or skips.
- Targeted single-mod/build/restore and seven-mod sanitizer tests: both passed.
- HUD synthetic regression verifies font and alignment constants survive the
  wrapper calls and archive compilation.
- Release-tag classification checked for stable v0.9.1/v1.0.0 and suffixed
  prerelease tags. Unsuffixed 0.x releases now publish as stable and latest.

The baseline reproduced one of the handoff's two VPS failures: single-mod GML
comparison lost alignment constant names after HUD setter redirection. Registering
wrapper argument types fixes the representation without relaxing equality checks.
The second VPS failure did not reproduce locally. The seven-mod sanitizer test
also depended on the live user's preconfigured library; it now imports explicit
fixtures into temporary storage, retaining every sanitizer and content assertion.

Verification covers archive compilation, references, sequential/parallel byte
identity, temporary installation/restore and headless GUI behavior. It does not
establish Windows hardware or in-game testing. Known product limits are listed
in the [release notes](../release-notes/v0.9.1.md).
