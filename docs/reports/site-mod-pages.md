# Mod detail pages

Run `python3 site/cgf-mods/make-packages.py` followed by `python3 site/cgf-mods/make-pages.py` to regenerate the site. The page generator reads package metadata from the catalog, generator names and versions from the recipe manifests, and the file lists directly from the ZIPs. The per-mod JSON files supply the descriptions and datasheets. The repository documents the supported legacy game version and the required features, so the pages omit a numeric JAMM minimum where no released minimum is established. [Catalog](../../site/cgf-mods/catalog.json), [legacy setup](../legacy-version.md), [release notes](../release-notes/v0.9.1.md)
