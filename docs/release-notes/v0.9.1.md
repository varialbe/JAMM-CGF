# JAMM-CGF v0.9.1

Stable release for the legacy 2023 version of Cat Goes Fishing. Game files and
copyrighted game assets are not included.

## Changes since v0.9.0

- Catalog merging keeps fish from multiple mods in distinct slots and saves
  catalog progress by name. Abyss and Cave fish can coexist in the catalog.
- Imported mods are sanitized by default to remove recognized third-party
  timing, throttling, distance-culling and debug-overlay changes while keeping
  content. Removed changes are listed per mod; Advanced mode offers an opt-out.
- A shared HUD layout stacks supported mod text and quests above the level bar.
- Smooth fixes replay Begin Step logic on input ticks, preserve sonar fish
  visibility and keep rod, lure and line poses consistent.
- Compact mod rows keep enable switches visible. Profile saves preserve conflict
  resolutions, and outdated patch caches regenerate automatically.

## Known limitations

- Windows packages have not been tested on physical Windows hardware.
- Play on Windows does not launch the game natively; launch it manually.
- Abyss and Cave still share the Boat8 object, sprite names and boat slot 8.
  Both versions of that boat cannot coexist; choose the preferred version when
  resolving conflicts. Catalog merging does not resolve this asset collision.
- itch.io downloads are unsupported.
- The legacy 2023 game is required. The current Steam build is not a supported
  merge base. See [legacy setup](../legacy-version.md).
- Compatibility results are guidance; test your chosen mod set in-game.

Packages include the Debian installer, portable Windows zip and Windows setup
installer. The CLI and compatibility scanner are also available as a GHCR image.
