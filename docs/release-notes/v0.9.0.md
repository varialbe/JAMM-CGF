# JAMM-CGF v0.9.0 — preview

This is an early preview for the legacy 2023 version of Cat Goes Fishing.
Expect rough edges; keep backups of your game and profiles. Game files and
copyrighted game assets are not included.

## Features

- Merge mods into one `data.win`, manage profiles, and review conflicts.
- Browse mods through Litterbox and Game Jolt, with computed contents and
  compatibility icons to help choose combinations.
- Use shared compatibility results from varialbe.xyz, with an opt-out.
- Detect the game on first run, including support for Flatpak Steam Play setups.
- Try the Smooth, HD, HD Lite and Perf example mods built via ModMaker.
- Install using a Debian `.deb` or Windows `.exe` installer, use the portable
  Windows zip, or run the headless CLI and scanner through Docker.

## Known limitations

- The Windows build has not been tested on real hardware.
- Play on Windows does not launch the game natively; launch it manually.
- Abyss and Cave have catalog slot collisions until the upcoming catalog API.
- itch.io downloads are not supported.
- The legacy 2023 game is required; the current Steam build is not a supported
  merge base. See [legacy setup](../legacy-version.md).

Please treat compatibility results as guidance and test your chosen mod set.
